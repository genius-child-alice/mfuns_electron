# MFuns 桌面客户端

## 常规设置（设置 → 常规设置）

仅在 Electron 客户端中显示，配置保存在 `userData/desktop-settings.json`。

| 选项 | 说明 |
|------|------|
| 禁用 GPU 加速 | 启动前生效，修改后需**重启应用**（设置页可点「重启应用」） |
| 关闭主界面时 → 最小化到系统托盘 | 点关闭后隐藏窗口，托盘图标可再次打开；Windows 会同时从任务栏隐藏 |
| 关闭主界面时 → 退出 MFuns | 与默认行为一致，关闭即退出 |
| 关闭时提示 | 关闭前弹出确认；托盘模式下可选「最小化到托盘 / 退出 / 取消」 |

## 开发

```bash
npm start
```

打包 Windows 安装包：

```bash
npm run build
```
